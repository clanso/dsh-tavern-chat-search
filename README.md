# 搜对话（dsh-tavern-chat-search）

DSH Tavern 插件：在右侧栏加一页「搜对话」，翻自己的聊天记录。

- **关键词搜索**：多个词用空格分开，要同时出现在同一轮里；都对不上时退一步列出包含其中一部分的。忽略大小写、空格和标点。可以只搜这一局或全部局，只搜自己说的、只搜正文或都搜。
- **让 AI 帮我找**：记不清原词时，用自己的话描述记得的内容。AI 先把描述扩成一组可能出现在原文里的词，插件把对话切成两三百字一段、按词粗筛出 50 段候选，AI 再按情节挑最像的 5 处，说明理由并逐字摘出原句。用这一局的后台模型，一轮调用两次。
- **多轮追问**（默认最多 3 轮）：AI 看完候选觉得都不像时，换一批说法再筛一轮，已经看过的段不再重复给它。
- **语义检索**（可选，默认关，在面板的「设置」里打开）：接一个 OpenAI 兼容的向量（embedding）接口，给每段算向量，按意思找，描述和原文一个字都对不上也能找到。按意思最像的 30 段和按词最像的 30 段交错交给 AI 挑。向量缓存在 `~/.dsh/dsh-tavern-chat-search/`，第一次要把全部对话算一遍，之后只算新增或改过的段。Key 存进 DSH 的凭据。
- **跳过去**：点结果跳到那一句并高亮几秒（会自动往前加载更早的消息）。关键词结果每处命中单独一行，点哪行跳到哪一处；AI 找到的点原句摘抄。在别的局里时先切过去，切不过去时提示你先打开那一局。「整轮」直接在面板里看这一轮的原文。

## 安装

打开 DSH Tavern → 设置 → DSH Tavern → 插件，粘贴本仓库地址 `https://github.com/clanso/dsh-tavern-chat-search`，点「安装」，刷新页面。
连不上 GitHub 时，下载本仓库 ZIP，在同一处点「上传 ZIP」。也可以把整个文件夹手动放进 `~/.dsh/profile-data/tavern/data/plugins/`。

装好后在右侧栏的「＋」里打开「搜对话」。要求 Tavern 插件接口第 2 版以上（DSH Tavern 3.x）；AI 帮找用这一局的后台模型。

## 说明

- 只读：用 Tavern 插件接口的 `getTurnState`、`getHistory` 读已经写完的正文，不改任何东西。读过的局记在内存里，没变就不重读。
- Tavern 没有「列出全部游戏」的接口，搜全部局时读 Tavern 数据目录下 `sessions.json` 的局号；读不到时只搜这一局和插件见过的局。
- 设置存在 Tavern 的插件数据里，向量接口的 Key 存在 DSH 的凭据里；向量缓存在 `~/.dsh/dsh-tavern-chat-search/`。
- 测试：`npm test`（不需要装任何依赖）
